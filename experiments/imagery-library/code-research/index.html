花瓣轮廓

下一步优先拆哪几块？

形态先看山水项目的树、石、舟与亭，以及花瓣生成；云和水波可试 Fresco 的装饰路线。鸟群已有上一轮的 NOC 完整示例。选定基础画风后，再验证笔触库能否让这些形态看起来属于同一幅画。

# 构图、自动光色与单体交互

2026-10-23 · 本地策略 `semantic-composition-3.3-world-instances`。协议仍为 3.3；没有新增模型调用。

用户实际测试发现岸水分割重复、夜色不暗、已有意象漏画、鸟群过小重叠及整层拖动。本轮从已保存的十次实际回答重放，原始回答和认可参考图不变。

## 修改

| 问题 | 当前处理 | 模块 |
| --- | --- | --- |
| 岸水布局重复 | 先提出连续水路与地表：横江、曲岸、斜江；池塘可环池，山溪可曲折穿林。按主次、远近安放现有实例，最终按重叠、重心等有限指标排序。已有五类风景继续可用 | `world-layout.mjs`、`scene-organization.mjs`、`landscape-development.mjs` |
| 夜晚浅底、整幅同色 | 夜晚优先靛蓝或金碧暗底，暮色保留暖冷变化；有限气息标签选本地方案。景物按角色与远近用色，靛蓝的树、水、山、建筑有各自色组；原文颜色保留证据 | `semantic-policy.mjs`、`drawing/core.js` |
| 小楼漏画 | 普通修饰词加楼、亭等自然建筑名可通过原文景物检查；专名仍不凭概念补房子 | `physical-mapping.mjs` |
| 鸟落水与重叠 | 水面依托不等于水鸟；只有水鸟姿态投到水域。动作未明只冻结时钟，不据此推断落地。最后检查位置与间距，不改变明确数量 | `semantic-policy.mjs`、`scene-integrity.mjs` |
| 月亮、鸟及花过小过淡 | 最后设置局部显示下限，防止主次与远近等多轮缩小叠加；远鸟仍比近鸟小，月亮与星点保持可读差别 | `scene-integrity.mjs` |
| 同类全体跟着拖动 | 每个实例有稳定 ID 和独立位移。竹林及裁切的连续地表默认成组；Shift 可拖同层整组。附着绑定具体实例，人物随船、炊烟随所属屋舍，其他船屋可独立移动 | `scene-integrity.mjs`、`scene.js` |

`imageryTrace` 记录已提取实体到图层、实例或风参数的连接及遗漏原因。它不表示已经找出了原文所有可见意象，也不表示每个笔触没有被遮挡。

“江碧”“鸟逾白”“山青”“荷花别样红”等有限颜色线索取自相关实体所在原句，并保存 `colorCue.evidence`；“花欲燃”用红色标记为 `local-color-interpretation`。模型仍不提供颜色代码、坐标或绘图代码。“荷风”借荷叶提示来源，标为 `whole-from-context` 并说明原句未明确看见荷叶；不补荷花数量。

## 验证与回看

- [十句改前／改后](../../poem-flow/composition-review.html)：点击改后图片进入动态画面，默认自动配色，无手动配色参数；可在同一回答上切换布局。
- `display-cases.json` 保存十次已发生调用的有效解读、旧规划和原记录 ID。两份曾作受限引用范围展开，重放页保留待复核说明；不改写原始失败。
- `display-regression.test.mjs` 加入七项回归，含九组新人工组合的数量、夜色、缺席与落点检查；人工语义不是新的 API 回答。全套 **111 项通过**，包括原二十图哈希与旧版本区域规划保护。
- `verify-display.mjs` 使用真实 Edge、p5 和鼠标事件：单只鸟、Shift 整群、竹林、还原、船上人物和具体屋舍炊烟随动，检查其他屋舍保持不动。还检查默认暗色、切构图保留手动色、动画、暂停、PNG 和 390px 窄屏；无页面异常、无 POST。
- 画面与浏览器结果保存在 `poem-flow/verification/composition/`，公开动态重放在 `composition-studies.json`；只含挑选的解读、必要来源和本地规划，不开放凭据或原始请求目录。

检查范围有限：尺度下限属于本地绘画选择，不能替代准确的视觉包围盒或审美判断；候选评分只比较已实现指标，无法证明是最佳构图。未实现完整物理承载、复杂遮挡、多阶段时间、任意隐含意象拆分或完整情感配色。当前整体风景与颜色仍需实际观看确认。

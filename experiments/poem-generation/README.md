## 2026-10-19：今日诗词候选初筛

主网页的“今日诗词 · 筛选”每轮通过官方浏览器 SDK **逐次请求最多 5 次，间隔 1 秒**。没有假设存在批量 HTTP 接口，没有改变用户 Token 或增加服务端代理。单次等待上限 8 秒，取句阶段总上限 25 秒（SDK 脚本加载另限 8 秒）；首次出错即停止，无自动重复取批。

`imagery-lexicon.js` 提供筛选与绘画映射共用词表，原有绘画映射行为保持。`recommendation.js` 做最长词优先匹配、标点归一去重、按不同可画工具类型排序；重复的花只记一次，柳絮不再拆成柳，月份与燕京等避免命中，风只在已有可画主体时加分。不同类型加分在 4 类封顶，已知不支持的词作小幅降分。相同分数保留接口返回次序。

自动填入本轮最优的可画候选，列表允许改选；若最多只有一类会提示匹配较少，全部无匹配则保留原输入。空结果、超长结果和超时不改写为本地样句。当前候选仅保留于页面内存，不后台累计诗库；点击生成才把选中诗句及出处交给 DeepSeek。字符匹配不判断否定、比喻、在场和具体语境，这些仍由语义流程负责。

验证：本地共 **33 项检查通过**；浏览器使用明确的测试 SDK 回答检验 5 次上限、去重排序、改选、无命中保留输入、部分失败停止和只提交选中一句。记录见 `../../poem-flow/verification/recommendation/fixtures.json`，其中没有真实模型请求。

另实测一轮官方 SDK：5 个成功响应、去重后 4 句，本轮最高仅匹配到 1 类，选中杨炎正《水调歌头·把酒对斜日》的“把酒对斜日，无语问西风。”。筛选阶段 **0 次模型调用**，点击生成后 **1 次真实请求，2334 token，4 秒**；语义通过，酒液单元可画，斜日未支持而列为缺口。原有基础逻辑保护因“无”而暂缓动画，未把这一结果宣称为完整的动景解释。请求保留在 `runs/2026-10-19T09-17-47-144Z-681ef646/`，浏览器证据在 `../../poem-flow/verification/recommendation/live.json`、`live-analysis.json` 和 `live.png`。本轮并未取到 2–4 类的丰富候选，不为此自动追加批次。

接口依据：[今日诗词官方文档](https://www.jinrishici.com/doc/)及官方 `jinrishici.js`；筛选与排序是本项目本地代码，未引入第三方筛选库。`node experiments/poem-generation/verify-recommendation.mjs` 使用测试数据；`--live` 实际取一批但不分析，另加 `--generate` 才提交选中一句。

## 本次范围

当前默认是 **基础意象模式**：沿用 3.0 的固定字段、原文证据、在场与比喻区分，但请求的子 Schema 要求 `relations=[]`。这是一项明确缩小范围的新请求，不是把前两次错误关系删除后冒充校验成功。完整 3.0 协议文件没有改动；完整关系抽取仍未通过此次样本检查。

- 模型不返回工具 ID、坐标、配色或代码；`planner.mjs` 决定已有工具与固定画面位置。
- 缺席物体、比喻参照、不确定主体与未做的具体物种不强行补画。地点不直接替换为建筑；明确的石上、水面等物体表面单独处理。
- 基础模式遇到否定／假设提示时暂缓动画，不宣称完成其逻辑范围分析。
- 月形不明时采用明确标注的弯月试画，并可手动切换。两组配色由用户选择，尚未自动对应 16 类情感。
- 各单元的数量、位置、比例和微动是观看试验；没有声称真实水流、石上流动、承载、遮蔽或跨物体物理关系已经实现。
- 28 个工具并不全部适用于任何诗句。无可用形态时保留空白并列明缺口。

## 本地接口与凭据

`service.mjs` 仅在后端读取根目录已忽略的 `llm api.txt`，沿用原有 HTTPS 地址、模型和关闭思考设置。密钥不发送到页面，不写入结果或请求快照。服务仅绑定本机，拒绝跨来源 POST，静态文件只开放明确的页面资产、已有绘画脚本与 p5；凭据、后台代码与运行目录不作为静态文件提供。

`GET /api/latest` 用于回看最后一次成功结果。点击生成时若输入与最近成功请求的提示词、模型、Schema 及本地策略版本均一致，直接使用该记录。其他情况会实际请求模型；失败不自动重试。

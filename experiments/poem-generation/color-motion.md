# 风景的色彩与动态

2026-10-23。用户优先整体风景，人物有基本写意设计即可；本轮不扩展人物细节和步态。模型输出协议仍为 3.3，没有新增模型请求，也不改写既有回答。

## 观看选项

- 22 套配色：设计规范原有的 16 组颜色、原有暮色／淡夜两组，以及本地新增青绿山水、朱砂晚照、金碧夜游、靛蓝月色四组。深底和鲜明色均可实际渲染，不只更换选项名称。六张快捷色卡展示四种基础颜色，完整方案在下拉菜单选择。
- 动态程度范围 0–200%，默认 140%。同时调节运动幅度和时钟，0 为静观，暂停按钮独立控制。风力仍单独控制局部风响应。慢／快语义倍率保留相对区别，不因观看设置改写原文。
- 水面增强波纹幅度与横向变化；飞鸟增加错相的有限位置变化与振翅幅度。树根、山石、地形不平移，房屋不随动态设置晃动；云雾与草木通过已有局部风响应变化。人物只随既有依托移动，不添加步态。
- 3.3 默认观看轻风为 0.3；明确缺席的风不补入，用户可自行调风。推断水域可以有本地水纹微动，仍标记为推断环境，不增加原文实体覆盖。
- 明确静止、可能或否定的动作不被动态滑块强行执行。运动是有限观看表现，仍不是多阶段叙事或完整物理模拟。

自动配色仍沿用此前的四种有限映射；本轮实现的是完整手动颜色选项，不是 16 类情感自动分类。重新生成另一幅图时按该诗语义重新选择默认方案，观看设置不写回原始语义。

## 代码与来源

`drawing/core.js` 提供唯一配色目录、可复制的选项元数据和有界动态设置；主网页与生成实验页共用。颜色来自 `docs/设计规范.md` 的原表；新增四种风景色是项目艺术选择。

`water.js`、`bird.js` 增强本地画法，`scene.js` 管理有限位移、暂停和附着；`semantic-policy.mjs` 设置 3.3 的观看默认值，`app.js` 与主网页显示色卡和滑块。未修改认可的莺意画笔或上游源码，没有新增外部绘图库。原作者与许可沿用 `drawing/sources.js`、`drawing/tool-manifest.json` 和 `poem-flow/THIRD_PARTY.md`。

## 实际验证

98 项本地检查通过，包括 16 组颜色与设计表逐项对照、数值边界、明确无风与静止主体。32 个工具独立浏览器检查通过，49 个上游原文件哈希保持，二十张认可参考图保留。

浏览器使用既有 s02 真实回答重放以及明确标记的人工动态校准语义，没有新增模型调用。22 种颜色均产生不同的画布像素。动态 50% 与 180% 的对照检查实际图层时钟、场景时钟及飞鸟位移；另核验动态归零、暂停、水纹像素变化、固定根部、静止鸟、舟与人影附着、PNG 数据及 390px 窄屏。几何和运行检查不代表审美验收。

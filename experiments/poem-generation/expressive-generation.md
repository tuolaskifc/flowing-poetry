# 写意归类与场景扩展

更新：2026-10-21。用户已明确同意房舍、鸟类和局部线索按写意原则概括。本轮改变本地绘画策略，语义协议仍为 3.2；原句、实体名称、数量依据和角色不改写成工具名称。

## 归类方式

| 原意象或线索 | 当前画法 | 保留的区分 |
| --- | --- | --- |
| 客舍、茅舍、草堂、房屋 | 低层房舍 | 用途仍保留在解读，不要求各做一套建筑 |
| 禅房、寺院、古寺、具名寺庙 | 寺院屋舍 | 不作具体朝代或真实寺庙复原 |
| 黄鹂、白鹭、燕、雁、鸦等 | 通用疏笔鸟形 | 可分浅鸟／墨鸟、飞鸟／停鸟／水鸟；原认可的莺形代码保持 |
| 马蹄、马蹄声 | 整匹马借形 | 四蹄不等于四匹马；同时有马与马蹄时不重复增加主体 |
| 桃花、杏花等 | 疏花枝或通用花形 | 原名称保留；枝数与花数分开，不作物种辨识 |
| 梧桐、芭蕉、松柏等 | 树木或针叶树意 | 不以专门叶形作为基本出图的前提 |
| 杜鹃 | 依据语义选鸟或花 | 多义保留；马蹄莲不画马，木兰舟、柏舟不画树，桂花酒不另画花 |

`expressive-mapping.mjs` 决定本地借形；词表匹配优先较长的词，避免短字抢先。来源被判断为缺席、比喻参照或出现情况不确定时，仍保留原来的过滤。可由明确的鸟鸣或马蹄声作本地身体联想，但不宣称诗句已经直接看见相应姿态。香气等没有现成合理图形的内容仍可保留为文字。

绘画列表会显示“鸟意（写意借形）”“马意（由马蹄借形）”等名称，具体原词义继续显示在语义解读中。未明说的鸟数默认作少量分布；明确两个保留两个，一行按群体安排，不将一行算成一只。

## 新的绘画与场景基础

新增本项目编写的 `dwelling.js` 和 `bird.js`，工具共 **31 个**。场景工具进一步支持水田、瀑布、天空、星点、日光、灯火、疏影、苔意、返照及静态轻尘。

- 房舍与马有局部淡墨承托，作为构图安排，不额外声称原诗明说地面或投影。
- 水田与夏木分区，树群集中在画面一侧，浅鸟与墨鸟有不同分布；减少整幅画被相同树冠叠满的情况。
- 瀑布用纵向水势、局部岩面与移动亮线表现；不是把横向江面旋转后当作瀑布。高度和局部结构是写意选择，不按三千尺换算像素。
- 疏影与苔意是局部笔触，返照是色层；尚未模拟真实光路、附着与倒影光学。
- 飞鸟已有翼姿微动，完整长距离飞行、马的连续步态、人物和完整时序仍未实现。

新增形态、场景布局和借形规则均为本项目代码。既有第三方归属保留在 [sources.js](../imagery-library/drawing/sources.js)；没有新增外部下载，也没有改动 49 个保存的上游原件。

## 验证

- `cd poem-flow; npm test`：61 项本地检查，包含房寺归类、鸟群与数量、四蹄不作四马、身体复指不重复、复合词与多义词、地名／否定／比喻边界。
- `node experiments/poem-generation/verify-expressive.mjs`：二十句手工语义对照；另检查花竹分区、月影、瀑布的实际画面变化、暂停、PNG 数据和窄屏，零模型调用。
- `node experiments/poem-generation/verify-expressive.mjs --saved`：四份真实结果零调用回放。
- `--live` 会请求四句；失败即停。不要把带此参数的运行当成本地检查。
- 主网页交互、精选库与新对照页的 40 张图片、60 项进度表、31 个工具生命周期与来源原件另行检查。

每幅作品仍记录具体缺口，不再把“尚未制作专门鸟种或建筑类型”一律作为不出图的理由。后续优先改画面主次、疏密、局部色彩和场景联系，而不是无限拆分物种名称。

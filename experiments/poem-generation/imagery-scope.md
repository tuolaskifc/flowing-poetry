# 意象范围与别称复核 · 2026-11-08

按用户反馈调整。原始统计 60 项；长安、南浦、潇湘退出绘画任务，归档在 `意象目录.json` 的 `archived_items`，进度表显示 57 项，原频次保留。本轮没有新增模型请求或外部绘画代码。

| 内容 | 当前处理 |
| --- | --- |
| 风、江水 | 用户确认当前范围足够，保留已有画法。 |
| 酒 | 当前生成默认酒壶借形，明确杯／盏时用酒杯，明确酒液时用液态。壶杯可分别组合；不因“酒”自动补杯或人物。酒壶默认是本地艺术选择。 |

| 秦楼 | 实景时复用楼体，不复原具体历史建筑。 |
| 梅子 | 接受果实与枝叶组合的方向；已有树枝依托，挂果尚未接入，保持部分支持，不以梅花代替果实。 |
| 兰桡 | 指舟船时复用舟身，不自动加桨；明确指桨时仍保留缺口。 |
| 羌笛、琴瑟 | 新增原创 instrument 工具：笛、琴、瑟及琴瑟组合；不补演奏者或音频。 |

别称映射同时核对推荐初筛与当前生成入口。先判断词所指、在场和数量，再由本地规则选择画笔；共用画法不会把不同主体合并。已登记别称可以对应，复杂借代和未登记词仍可能出现缺口。历史明确保存的计划保留旧表现。

176 项测试通过；进度页 57 项、四类筛选、390 宽布局和 15 个试画深链接通过。真实浏览器检查酒壶／杯、菊丛、女子、长亭、笛与琴瑟的绘制及数量，未发现运行异常。预览：[六组画法](../../poem-flow/verification/rules/scope-preview.png)。新画法待用户审美确认。

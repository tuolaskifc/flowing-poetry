# 满幅笔势

2026-10-24 · 本地画法 `canvas-gestures-1.0`。入口：[放开画幅](../../poem-flow/expanse-review.html)、[融合试画](../../poem-flow/expression.html?case=u02&mode=abstract)、[抽象试画](../../poem-flow/abstract.html?case=a03)。语义协议沿用 `expression-1.0` 与 `abstract-1.0`。

## 为什么修改

此前抽象形态仍以主体为单位，局部尺度和场景裁切使它们容易变成小块装饰。现在把景物材质与自由笔势分开。材质依附景物轮廓；自由笔势在整个画幅中组织走势，可以覆盖、交叠、越出边缘。铺满不要求所有像素着色，弧线和游丝仍可保留大块呼吸空间。

| 画法族 | 满幅构造 |
| --- | --- |
| 流线、网织、丝带 | 长曲线横穿画幅，多方向交叠；丝带形成有宽度的渐变色面 |
| 墨晕、浸染 | 多层大面积色团交融、边缘裁出、内部细脉 |
| 涟漪、等高纹、叠影、涡流 | 偏心大弧与螺旋从画外切入，半径超出画布 |
| 碎片、裂隙 | 扰动格点覆盖全幅，大小色块之间留出缝隙 |
| 微粒、游丝 | 贯穿全幅的粒子场、长纤维与侧向分枝 |

`gesture-field.js` 由项目编写，无新增下载代码或生成图片。以确定性种子选择走势、旋向、中心、色彩和相位。优先以明确存在的抽象主体组织笔势；没有抽象主体时可从已有可绘景物借取画法。缺席、背景上下文与尚无画法的地点不获得自由色场。候选仍以较弱、虚线或不填实的方式表现；延续、消退等成立状态沿用已有节点透明度。自由笔势标记为 `local-artistic-choice`，不当作诗中真实物体。

## 观看控制

两页新增“铺展程度”0–1，默认 0.9；0 保留局部画法。融合页风景优先不加自由笔势、景意交融采用半强度、抽象优先充分展开。景物实例、明确数量、位置与依托共享原计划。满幅笔触响应点击与触摸扰动；换种子、还原和暂停仍使用原交互。相同种子、参数、时点与交互历史可复现。

旧抽象预设和上一版十八张融合对照显式使用 `expanse:0`。原 PNG、请求与原始回答保留，旧图片不被新版本覆盖。新图片单独位于 `poem-flow/verification/expanse/`。

## 对照与验证

重用统一表达的六份既有真实解读：六组局部／满幅共十二张，加“剪不断，理还乱，是离愁”十三类满幅画法，共二十五张。没有新增模型请求，也不作为新诗泛化成绩。各诗来源与原回答复核边界继续见[统一表达记录](shared-expression.md)。

`verify-expanse.mjs` 用实际 Edge Canvas 检查满幅覆盖、参数和像素复现、景物与语义锚点不变、点击扰动、滑块和手机宽度。自由笔势单独绘制后检查横跨与纵跨范围，允许有意识留白；这些检查不代表审美验收。另只读对照十二张旧抽象预设，并核对旧记录及图片文件哈希。

实际结果：完整 **139 项测试通过**，二十五张新画面、六张前后拼图与 390px 手机页面已生成并检查；十三类笔触均能横跨画幅。十二张旧预设在本次与上一版代码中完全一致，169 份历史文件哈希保持，重放期间没有模型 POST 或浏览器异常。历史 PNG 对照中六张无变化，另六张有少量栅格差异，其中最大单通道差 14、涉及 335 个通道值；同环境的旧实现也得到同样结果，未覆盖原图。

旧预设另在同一浏览器中分别使用本次代码和上一版提交 `5b529a1` 重放，要求两者逐像素一致。与更早保存的 PNG 另行记录栅格差异；旧实现本身在当前环境下也存在少量差异，因此不把历史 PNG 的字节一致性当成本次通过项。历史文件哈希独立检查，不改写旧图。

自动结果见 `verification/expanse/verification.json`；当前审美状态为 `pending-user`。同一种风格在不同诗句和种子下仍可能过密、过淡或抢走主体；可通过铺展、疏密、配色与表达档位继续调整。

## 唯一数据源

编辑 `curated-poems.json`，主网页与总表读取同一份记录。没有另外维护一份硬编码推荐数组或手填网页表格。

| 字段 | 内容与维护方式 |
| --- | --- |
| `id` | 稳定编号，如 `p01`；删除或重排以外的调整不更换编号 |
| `poem` | 实际送入语义流程的原句，1–200 字，不含现代译文 |
| `author`、`title`、`dynasty` | 书目信息，与在线文本来源核对 |
| `source` | 原文链接、实际核对日期、版本与核对说明；曲径／竹径等异文注明采用写法 |
| `focus` | 是否列入本轮优先改画的样本 |
| `imagery` | 人工整理的线索，声音、气味和比喻参照明确标注 |
| `goal` | 希望改进的构图、层次或关系，是目标而非已实现事实 |
| `available_tools` | 现有基础单元盘点，允许为空，不表示完整场景可画 |
| `gaps` | 缺少的形态、画面联系及语义边界问题 |
| `baseline` | 已有基础出图情况或待生成状态，不把出图等同审美通过 |
| `review` | 当前使用“待改画”“待试画”；只有用户认可具体效果后才记“已认可” |

涉及完整关系、色彩、时间、否定范围的目标保持待实现。此轮没有修改绘画算法，不能把建立候选库视为画质已经改善。

## 选句与生成

主网页默认填入首批第一组；下拉框可选择所有 20 组，“换一句精选”按重点在前的顺序循环。总表支持作者、诗句、意象与目标搜索，以及重点／效果进度筛选。“带入主网页”使用稳定编号，如 `/?poem=p03`，只带入原句，不自动调用模型。

手动编辑、使用样句或在线候选会清除当前精选标记。打开页面只读取本地配置状态、最后结果与精选库，不自动生成，也不自动显示旧画；旧画保留在“回看上次结果”。

点击生成时，仍发送 `{poem, source}`。`source` 只含来源标识、作者、篇名与朝代；人工意象、目标、缺口和认可状态不会进入模型提示，也不替代语义检查。冻结语义协议与已有绘画算法没有修改。

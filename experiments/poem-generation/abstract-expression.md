# 抽象诗句表达试验

2026-10-23 · 独立协议 `abstract-1.0` · 本地策略 `abstract-expression-1.0`。这是可运行的实验入口，风景生成默认继续使用 3.3。

入口：[抽象试画](../../poem-flow/abstract.html)、[四句／32 张对照](../../poem-flow/abstract-review.html)。可以输入新诗句请求 DeepSeek；已有四份回答直接重放，不请求模型。改变画法、种子、颜色、疏密、动态和拖动均在本地进行。

## 职责与实际能力

| 部分 | 实现 | 边界 |
| --- | --- | --- |
| 语义解释 | `abstract-contract.mjs` 定义主体、关系、过程、气息及依据；模型不提供坐标、色值或代码 | 最多五个主体、六项关系及五项主导过程；不是完整文学解释或多阶段剧情 |
| 本地规划 | `abstract-plan.mjs` 保留在场、候选、缺口与比喻借形；纯时间词不独立造形，解释问题仍显示 | 不把缺席物画成实景；不确定性不等于随机发生概率 |
| 绘画 | `abstract-scene.js`：流线、墨晕、碎片、丝带、涟漪、微粒、等高纹、叠影、网织；交融模式组合不同笔触 | 笔触数为装饰密度，不表示原文事物个数 |
| 随机 | 五种基础空间分布、八套色组及节点尺度、弯曲、频率、笔触数量和相位变化；种子可复现 | 同种子、画法、参数与播放时点复现相同像素；种子不改语义关系或其成立状态 |
| 关系 | 趋近／分离、汇聚／分散、包围、呼应、对照、交织、连接、受阻及有限显隐 | 为有限几何与透明度映射，不是完整物理相互作用；显隐尤其尚无复杂遮挡系统 |
| 时间 | 区分已经、尚未、正在、再次和反复；已经消退不重新播放消失，尚未不自动开始，非确定过程不执行 | 秒数和播放安排属本地艺术选择；一次过程不默认无限循环 |
| 交互 | 逐个拖动、保留拖动旧迹、还原、重放、暂停、疏密、运动、PNG | 包围形态与内部形态按联系移动；留痕窗口属观看选择，不冒充诗句事件 |
| 景物叠加 | 在“月、楼”样本中，把原文明说且在场的具体主体投给现有画笔，再叠加抽象层 | 这是明确标注的本地适配，不是假造第二份模型回答；抽象协议尚未接入精确景物数量、景物下移与复杂空间约束；混合时关系端点固定在实际景物位置，变化主要由抽象层提示 |

夜景自动变体只从四套暗底中选择；用户仍可主动试亮色。抽象动画最多约 30 帧每秒；暂停与动态程度为零时停止持续重画。风景模式与抽象模式的最近结果分别缓存，抽象回答不会覆盖主风景页面的回看。

## 原句来源

文字按以下原文节选转简体，作者和来源用于署名，不发送本地绘画目标给模型。

- 李商隐《锦瑟》：[原文](https://zh.wikisource.org/wiki/錦瑟)，取末联。
- 陶渊明《饮酒·其五》：[原文](https://zh.wikisource.org/wiki/飲酒二十首#其五)，本版依来源用“欲辩”，另有“欲辨”版本。忘言不按医学失忆解释。
- 李煜《相见欢·无言独上西楼》：[原文](https://zh.wikisource.org/wiki/相見歡_(無言獨上西樓,_李煜))，取“剪不断”三句；不据篇外内容补楼、月或人物。
- 李益《写情》：[原文](https://zh.wikisource.org/wiki/寫情)，取末联，用于具象景物与抽象心境叠加。

九类抽象画法与 Canvas 交互代码由项目编写，没有下载新绘画代码或使用生成图片。混合模式的月、楼等沿用已有工具及其来源说明。

## 首次真实调用与检查修正

四次实际 DeepSeek 请求，各一句、一次，无自动重试。首次结构校验 **3/4**，接口记录共 **8341 token**。请求、原始文本、Schema、首次结果和用量保存在 `poem-flow/verification/abstract/`，服务器只公开其中 PNG，不开放这些原件。

“忘言”一份首次被拒：主体“言”被解释为结果缺席，但存在“消退已发生”和“表达受阻”的确定项。最初检查器把所有缺席端点一律禁止，过于严格。随后只修正检查条件：`fade + already + absent` 可描述既有结果，`block` 可指向缺席目标；其他缺席主体不能执行确定动作。**没有更改回答中的主体、关系、过程或引文，没有追加请求。** 原拒绝保持在 `a02-record.json`；修正检查后的独立重放在 `a02-replay.json`，带 `localRevalidation`。新解释仍需文学层面复核，不把本地重放改报为首次四次全通过。

“锦瑟”回答还把“当时”列作抽象主体；本地不独立造形，原回答保留，并显示待复核。“可待”的反问歧义、忘言的哲学意味、剪与理的比喻角色等亦保留在解读与说明中。结构通过和画面丰富均不等于这些解释已经正确。

## 验证

- 完整测试 **120 项通过**，包括原风景 111 项和新增九项抽象检查。
- 新检查覆盖原始失败保留、证据与 id、缺席结果边界、候选／比喻／缺口区别、120 组确定性种子与画法组合、40 组自动夜景配色、模态与时间范围、真实服务调用路径的隔离缓存。
- `verify-abstract.mjs` 使用 Edge 与真实 Canvas 生成 32 张图及四张拼图；同种子、画法、时间逐像素复现。实际鼠标检查单体拖动、留痕和还原，另检查种子、画法、时钟、暂停、PNG、混合开关与 390px 窄屏。重放期间没有 POST，没有新增模型调用。
- 图像与 `verification.json` 含当前模块哈希；同批调图是回归，不作为新的泛化试验。审美状态仍为 `pending-user`。

这轮探索为具象场景增加氛围层提供了可复用笔触，但尚未自动把抽象关系叠加到每一首风景诗。当前混合试验从原句已提取的景物开始，后续要验证遮挡、视觉重心、数量与文学解释的协调。

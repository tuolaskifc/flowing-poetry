# 共用绘画规则 · 2026-10-25

上一轮的 13 组改图现已接入后续生成过程。入口：[12 组换句验证](../../poem-flow/rule-review.html)；[前轮前后对照](../../poem-flow/refinement-review.html)保留为当时结果。本轮没有引入新的外部代码或模型请求。

## 共用流程

诗句 → 模型语义解释 → 校验与分级恢复 → 原文绘画复核 → 区域／候选构图 → 共用绘画策略 → 最终几何检查与排序 → 原生风景及抽象表达。

`planner.mjs` 的当前生成路径调用 `drawing-policy.mjs`。3.3 主风景、统一表达的三档、当前服务中新生成的 abstract-1.0 景物适配及缓存回答重放均使用它；依托此前仅连接统一表达入口的遗漏已经补齐。抽象关系、比喻与缺席主体不会因此变成实物。旧预设的显式计划和独立历史适配默认保持兼容，原回答、前后对照图和基准文件不重写。

| 可复用能力 | 规则和限制 |
| --- | --- |
| 明确数量 | `source-resolution.mjs` 从贴合主体的量词复核计数，支持“一对／两双”、二十三等连续汉字数词、阿拉伯数字和多种个体单位；三两等范围、枝条等局部计数保持原边界。不强改否定／假设，也不取别的名词的数量。独立记录原值、绘画解释、引文及个体数，原语义不变。 |
| 同指人物 | 肯定的“吾乃旅人，旅人亦为归人”等身份链可共用一个人影；保留所有主体 ID。并列、否定和假设不归并。复杂指代仍不保证解决。 |
| 每个名词自己的颜色 | `source-colors.mjs` 共用于原生画笔和交融纹理。“红梅白菊”分别保色，不跨名词借色；黄鹂等物种名不直接当作颜色形容。无明确颜色时继续按本地色组表达。 |
| 手持与依托 | `source-dependencies.mjs` 检查持剑动词是否与剑相连；同句“持酒”不牵连另一句的剑。只有已有且归属明确的人／屋／树可作依托，不能凭道具补主体。多面酒旗分配到具体屋舍实例；过多或归属不明时不强行堆到同一锚点。 |
| 可见度和遮挡 | 关键主体、明确颜色和瀑布等有共用的 visibility 标记，交融后保留轮廓；明确“鸟在叶后”等遮挡优先，不因轮廓保护反转前后关系。 |
| 独立物体避让 | `subject-spacing.mjs` 用原生画笔相对锚点的像素边界检查舟、马、人、兵器和酒器，保持已有水陆区域、数量及尺度，在局部候选点里减少重叠。附着物跟随具体父实例；明确相依或前后遮挡不被避让拆散。最终候选排序兼顾剩余重叠。无合适位置时保留局限，不靠删除物体消除冲突。这是有限平面避让，不是物理模拟。 |
| 内容与推荐 | 酒旗／旌旗／常见颜色旗幡、剑／戈矛及市集写意归类同时接入本地词表和画笔选择。“酒旗”不再额外推荐酒液，“剑阁／剑南／剑门”不拆成剑。新增旗幡和兵器画笔为项目原创；三十四个工具的既有来源登记保持。 |

原始语义与本地选择分开保留：`sourceResolution` 记录计数和身份，`drawingPolicy` 记录各候选的保色／可见度／依托，`scene.organization.actorSpacing` 记录移动和剩余重叠。它们说明绘画过程，不冒充模型的新回答。

- 12 组自编短句与手工语义，检查两对白鹭、二十三只鸟、三舟两马、三称谓同指、并列人物、多面酒旗、持酒与独立长剑、红梅白菊、绿柳白云青山、缺席旗幡、兵器比喻及局部枝数。它们验证本地规则，不验证大模型读诗能力。

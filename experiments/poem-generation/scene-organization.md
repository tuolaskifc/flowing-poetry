## 实现与边界

通路：原句 → 模型语义与原文依据 → 严格语义检查 → 基础画法与数量 → 区域构图提案 → 通用组织与监督 → 本地绘制、交互和保存。

`scene-organization.mjs` 由 `planner.mjs` 调用，接在现有数量与区域规划之后。已有区域提案继续保留，未匹配组合使用通用约束；一月、一舟、露珠等局部习作保留，明确成片的树林可以组织成环境。

| 层次 | 已实现 | 边界 |
| --- | --- | --- |
| 场景图 | 记录地形、水域、植被、主体、动物、天空及气氛层；原文关系与本地依托分开 | 只能检查已提取内容，不能发现模型遗漏的原文意象 |
| 共同区域 | 水岸分区、根部和房舍落地、舟鱼和水鸟进入水域 | 构图区域不等于真实地形或流体模拟 |
| 环境补充 | 必要时补地面或水域，保留 inferred、原因和空实体 ID | 对应环境的缺席、参照或不确定状态阻止补画；不提高原文意象覆盖数 |
| 群落与尺度 | 植被分群、远近与透明度；草本比树木小，大主体群缩小分散 | 未明说的疏密与远近是本地选择，不是真实株数 |
| 数量与关系 | 保留数量及显示限制；主体落点不重复三个槽位；承接部分水上、树冠、邻接、外侧、前后、月影关系 | 局部、声音、范围计数及未适配关系继续提示 |
| 局部附着 | 一缕烟靠近村舍起笔，拖动村舍时一起移动，标明本地选择 | 不补烟囱、灶火或人物，不模拟真实烟气 |

受控原词别名补入柳树、杨柳、渡头、墟里、远村、近村、高原。专名不会因为模型概括为“村落”就补成房屋。新增画法为项目原生：landscape 柔化地表边缘、mist 一缕烟；没有新增外部绘画代码或依赖，原有来源与许可沿用登记，49 份原件哈希保持。

## 自动监督

通用组合生成三个布局，比较左右岸、主体位置和群落分布。硬检查包括在场、明确数量、有限数值、锚点、适用依托、尺度与相对位置；近似轮廓重叠和重心只作软比较，没有“越填满越好”的奖励。

每个提案最多两轮几何修正，仅处理陆上／水上落点、过大尺度及画外锚点；错误数下降才接受，保存前后位置和轮次。数量与语义错误不会靠复制、删除或改写实体消除。已有区域与局部习作使用检查子集，`checks` 明列适用范围；未画线索和未适配关系列为待复核，风等参数单列。

这些近似指标不能发现所有实际像素遮挡。`checks-passed` 仅表示当前适用规则未报错，审美状态始终另列 `pending-user`。检查发生于生成时，用户自由拖动后没有持续强制纠正。

## 自查和迭代

1. 八个人工组合练习检查地面、水域、群落、双数、树冠和环境缺席；它们是人工语义，不是模型结果。
2. 首轮截图发现花叶完全重叠、草本过大、地表轮廓过硬；分开中心与层次、缩小草本并柔化地面。初版证据保留于 `poem-flow/verification/organization/round1/`。
3. 六句新诗调用期间固定规则，没有逐句修改或重试。之后复查发现普通地点漏画、薄雾冒充一缕烟；补别名、烟形、村舍附着与岸面裁切。首次结果保留于 `first-live-layout/`，原始回答不改写。当前图片是同批优化回归，不作为新的独立泛化成功率。
4. 向检查器注入船在水外、树过大、删除明确计数、无效位置和未知实体等错误，确认能报错；验证有限修正只修几何问题。另组合五类植物与四类动物，覆盖二十种非逐句特判组合。

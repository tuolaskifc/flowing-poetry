# 数量解释与群落构图 · 3.1

更新：2026-10-21。本数量模块已由主网页默认的 [3.2 场景扩展](scene-generation.md)继承；显式 quantity 模式仍可单独使用。完整的冻结协议 3.0 文件不改动；本扩展在其实体上增加 `quantity`，仍要求 `relations=[]`，不表示完整关系抽取已完成。以下保留数量阶段的实现与验证记录。

## 分工

诗句 → 模型解释意象及数量依据 → 本地校验 → 本地选工具、组织群落 → 透明画布合成。模型不决定坐标、显示份数、近远层次或代码。

原先同类工具会合并成一个图层，图层只画一次，部分工具又内含固定的一簇。因此既无法表现“一片”，也可能把“两朵”误画成两簇。本轮区分语义实体、显示单元和底层绘画实例：同类实体可以共享图层，一个图层可以有多个位置，最多复用三个带不同种子的源画布。

## 数量字段

所有实体必填以下字段，`schema_version` 为 `3.1`。定义、提示词与校验器见 [quantity-contract.mjs](quantity-contract.mjs)；在旧协议的结构检查之外验证字段、整数边界、原文依据和实体关联。

| 字段 | 允许内容 |
| --- | --- |
| `mode` | `exact` 明确数量、`range` 数量范围、`few` 不精确的少量、`many` 群体或繁多、`unspecified` 数量未明 |
| `min`、`max` | exact 为相同非负整数，range 为原文支持的整数边界；其余为 null |
| `unit` | 原文中的量词／单位，未明确为 null |
| `scope` | `individual` 个体、`part` 局部、`group` 群体单位、`extent` 距离等范围、`unspecified` 未定 |
| `extent` | `local` 局部、`spread` 铺展、`unspecified` 未定 |
| `evidence` | 至多三段连续原文，关联本实体；不能编造依据 |

“两朵花”与“一叶孤舟”按个体计数；“一行鸟”计群体，不能变成一只鸟；“十里荷花”计范围，不能变成十朵；“三两枝柳”指局部，不能变成两三棵树。“无穷”也不应触发“无”的全景冻结保护。

这些检查验证结构和引用，不是完整的汉语数词推理或文学判断。实测仍出现以实体名充当单位、把未明说的单体推断为 exact 的回答，需人工审阅；原始回答保留，不自动改写成正确答案。

## 本地显示规则

[composition.mjs](composition.mjs) 在已有工具范围内工作：

- 支持的个体数量明确时按该数量绘制；范围内选一个本地试画数，未明与繁多也用明确标注的本地份数。群体单位的数量仍保留，但尚未实现按“行”“丛”分别组织的拓扑。
- 花、草、竹和红黄叶新增 `singleUnit` 绘制选项，默认关闭，保持独立工具页的七株花、九簇草、三竿竹、五片叶。生成器使用单体，避免重复放大内部数量。兰的明确花部计数使用单花模式。
- 花草竹兰等可在多个位置聚成景；莲叶与荷花分别布置近、中、远层次，按高度次序叠画。缩放、透明度、疏密和变体由本地种子规则确定。
- 一株柳可作为画面侧面的较大主体；水纹、孤舟等调整占幅。保留明确单体，不为填满画面增加人物、物种或未提到的池水。
- 每层最多 48 个、全景最多 112 个显示单元。超出时保留语义数值并说明显示限制，不称为已完成精确计数。局部计数缺少画法时单独标注；雨雪、云等整体笔触工具尚未按内部颗粒逐个计数。
- 当前“换形态”改变源画布几何，保持群落布局；拖动一处笔触会移动同类图层的整组实例，支持还原布局。交互不新增模型调用。

旧记录没有 quantity 时，只在包含该实体的原文分句内识别少数群体提示作为本地兼容处理，标记 `basis=local-legacy`。它不冒充当时模型的数量判断，也不改写历史请求。

## 验证与证据

本轮实际调用模型 **2 次，6055 token**，没有自动重试。模型返回、提示词、Schema、请求及用量见：

- `runs/2026-10-21T11-33-05-323Z-52afa0cc/`：接天莲叶无穷碧，映日荷花别样红。
- `runs/2026-10-21T11-33-09-247Z-ca41dd7e/`：孤舟蓑笠翁，独钓寒江雪。

前者得到繁多／铺展的解释，本地绘制 40 片叶和 16 朵花，复用六个源画布；这些份数是本地构图选择。后者仍只有一舟，人物与寒江的专门画法保留为缺口。

对照使用**同一份语义结果、同一版绘画工具**，分别运行 `d9220b5` 的旧规划器和当前规划器；这是受控重绘，不是过去截图。荷塘的着墨区域约从 1.8% 到 38%，仅用于检查确实铺展开，不作为审美分数。荷塘局部形态、红碧对照和光照仍待改，候选表保留“待改画”。

证据在 [quantity 验证目录](../../poem-flow/verification/quantity/)：`live-*` 为实际请求与首次对照，`real-replay-*` 为零新增调用的最终交互回放，`fixtures-*` 为明确标记的手工语义样例（含两朵花与一舟）。群落拖动、还原、换形态、暂停、PNG 数据导出和 390 像素窄屏通过浏览器检查；没有操作系统下载确认界面。

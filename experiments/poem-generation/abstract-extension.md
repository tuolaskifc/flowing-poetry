# 抽象表达第二轮扩展

2026-10-23。独立协议仍为 `abstract-1.0`，本地策略为 `abstract-expression-1.1`，主风景通路保持 3.3。入口：[抽象试画](../../poem-flow/abstract.html)、[新 40 图](../../poem-flow/abstract-extension-review.html)、[原 32 图](../../poem-flow/abstract-review.html)。

## 已实现

| 画笔 | 视觉构造 | 种子变化 |
| --- | --- | --- |
| 涡流 | 多臂螺旋、弯曲中心和不同半径的流迹 | 旋向、圈数、起点、伸展、尺度、相位与配色 |
| 浸染 | 半透明色层、毛边和分叉细脉 | 分瓣、边缘、漂移方向、纹理与层间色彩；属于程序纹理，并非真实颜料模拟 |
| 裂隙 | 扰动格点形成分离色片、片内细缝 | 格点、缝宽、尺度、碎片密度和轻微错动 |
| 游丝 | 有共同走势的细长纤维与侧向分枝 | 根部、长度、展开角、分枝、细线密度与摆动 |

画法共十三类，加一个交融选项。新交融可混用新旧笔触；原预设使用 `vocabulary: classic` 固定原九类自动选择，避免缩略图与重放变成不同形态。夜景自动选择仍限于四套暗底，用户可主动试亮色。没有新增下载的画笔代码；四个算法与交互均由项目编写，景物叠加继续沿用已有画笔来源。

点击或轻触画面会出现波前，并使邻近抽象形态短暂偏移、扭转；距离、波前和观看时钟共同决定响应。默认回应强度 65%，可归零，键盘可操作“轻拨画面”按钮。拖动超过阈值便只拖动和留痕，不额外触发点击。每次扰动最多保留八秒观看时间，最多十二个；暂停冻结时间，还原、换预设、换画法、换种子会清除扰动与留痕。确定性复现需种子、参数、观看时点及相同交互历史。

扰动属于用户的观看行为，不改变语义节点、原文证据、条件或否定，不将未然过程变为已发生；具体景物在混合模式中保持原画笔与锚点。缺席／候选状态现在优先于比喻角色，缺席的参照不会因“借形”而获得实体。

## 新诗与真实请求

仅给三句新诗各一次 DeepSeek 请求，没有自动重试、补请求或人工改写回答；首次结构检查 **3/3**，返回记录用量 **6613 token**。初始四次请求的 capture 与原失败记录保留，新批单独记入 `poem-flow/verification/abstract/extension-capture.json`。模型仍只接收原句，作者、来源与编辑目标不进入模型输入。

| ID | 原句与出处 | 检验点与复核 |
| --- | --- | --- |
| a05 | 李煜“问君能有几多愁？恰似一江春水向东流！”；[《虞美人》原文](https://zh.wikisource.org/wiki/虞美人_(春花秋月何時了)) | 春水保留为比喻参照，只借抽象流动特征，不补造实景江岸；“向东流”被另列主体，仍需判断是否过度拆分 |
| a06 | 秦观“两情若是久长时，又岂在朝朝暮暮。”；[《鹊桥仙》原文](https://zh.wikisource.org/wiki/鵲橋仙_(秦觀)) | 条件不自动执行，“又”不触发无限循环。模型将朝朝暮暮标为缺席，但“不必朝夕相守”不能推出“没有相守”，页面明确提示 |
| a07 | 苏轼“人生如逆旅，我亦是行人。”；[《临江仙·送钱穆父》原文](https://zh.wikisource.org/wiki/臨江仙_(蘇軾)/送錢穆父) | 模型误把逆旅并释为逆行旅次；[教育部词典](https://dict.revised.moe.edu.tw/dictView.jsp?ID=57514&la=0&powerMode=0)释为旅馆、客舍。页面标出原解读的词义问题，原回答保持不变，不生成逆行剧情 |

三次结构通过不等于三次文学解释正确。浏览器把复核说明与原回答并列，未静默替换原始字段。诗句文字按所列原文转简体，保留公有领域作品出处。

## 验证与保留

- `npm run check` 与完整 **124 项测试通过**。新增检查包括比喻水不补实景、缺席参照不借实体、条件／否定不自动执行、有限且可复现的扰动、原九类自动预设兼容。
- `node experiments/poem-generation/verify-abstract-extension.mjs` 用实际 Edge Canvas 生成 **40 张新增图、七张拼图**；四种新画法均检查动态变化，固定参数及交互历史可逐像素复现。
- 实际鼠标检查点击与单体拖动、留痕、暂停、还原、种子清空；390px 页面实际触摸也可触发。响应强度归零、最多十二项扰动、八秒后过期均通过。页面无横向溢出，浏览器异常为零，重放中 POST 为零。
- 原 capture、原 32 张图与旧对照页按 SHA-256 前后比对保持不变；另将原 a01 八种预设重新绘制于内存，与原 PNG 逐像素输出对照通过。验证摘要、模块哈希与图片哈希见 `extension-verification.json`，原始请求与回答只保存在本地，不由服务器公开。
- 新图是三句新回答和四句既有回答的本地变化；同句变体与后续改图不作为新的独立泛化成绩。审美仍为 `pending-user`。

当前自动画笔选择主要依据种子及有限关系，尚未建立完整的情绪到笔触和色谱映射；复杂舞台时间、真实流体、文学词义自动纠错及把抽象层普遍接入主风景仍未实现。

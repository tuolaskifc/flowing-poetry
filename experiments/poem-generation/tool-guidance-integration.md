# 工具目录与正式生成接入

主画诗入口的 `expression` 通路现在在一次模型请求中附上工具目录，请求语义与 `tool_selection` 一起返回。原语义仍按 expression-1.0 验证；工具建议单独保存和检查主体 ID、在场状态、工具 ID、字段及原文依据。建议完整通过后，合格主体的工具 ID 才传入本地绘画计划；源词的明确限制、数量和共用构图仍执行。若建议缺失或无效，保留已通过的语义并使用原有本地映射，首页提示采用原有画法。模型的预期和文字构图作为待审信息，不是已经实现的画面。

缓存重放重新检查建议，再使用当前绘画规则；旧记录没有选笔建议时沿用本地映射，不伪造历史回答。模型建议不能执行代码、提供坐标或绕开缺席／比喻主体。部分不支持形态或已消退状态仍不能可靠表达，`landscape` 的具体变体只能在本地已有可用映射时决定；梅子等已知果实缺口不会借梅花冒充。结构检查不能保证所有新词映射正确，需继续对照实际画面。

真实接口单次检查：使用“孤山寺北贾亭西，水面初平云脚低”，一次返回合法解读与工具建议，记录用量 9,345 token；模型建议寺、亭、水、云，计划相应使用 dwelling、pavilion、water、cloud。保存结果在 `output/production-tool-integration-2026-11-08/record.json`。用该真实结果代替请求在本机首页绘制，截图 `home.png`；浏览器渲染没有新增模型请求。图中亭与寺有明显重叠，空间布局与审美仍未通过用户验收；此单例不是陌生诗句成功率。

新增模拟接口测试覆盖一次请求返回、工具生效、缓存重放及无效建议退回原映射。原有完整测试套件与针对性检查通过。

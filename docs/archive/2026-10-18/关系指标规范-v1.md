# 流动诗：关系指标规范 v1

记录日期：2026-10-18。

本版整理“关系”的含义、候选类型和绘画约束，作为后续设计依据。视觉关系尚未实现或验证；本文没有修改现有语义协议、提示词、配色表或网页。文中的绘制方式是待试验的艺术方案，不是诗句的唯一解释。

## 1. 关系负责什么

关系描述两个或多个图形怎样联系、怎样相互影响。它可以约束位置、距离、路径、依附、遮挡，以及相互响应。

各指标分工如下：

| 指标 | 职责 |
| --- | --- |
| 意象 | 提供需要表达的事物与形态线索 |
| 情感 | 对应用户的 16 类配色方案，负责颜色选择及使用方式 |
| 强度 | 控制图形紧密度、笔触密度和空间利用程度，不以改色或加速代替 |
| 关系 | 决定图形怎样相处、联系和相互影响 |
| 逻辑 | 确定具体意象、动作或关系是成立、否定、可能、条件假设，还是暂不明确 |
| 时间 | 决定关系怎样展开、持续、反复或留下变化 |

强度采用三档还是四档尚未最终确定，本文不替用户锁定档位或数值。主体数量依据文字及明确的艺术选择；提高强度不能自动解释为增加人物、船只等独立主体。

## 2. 分开记录诗句含义与图形选择

诗句先提供语义关系，项目再选择视觉关系。

例如，“长风万里送秋雁”的“吹送”可以采用“牵引”表达；是否再让雁阵穿过画面、远离视点，是构图与时间上的选择。LLM 提取的语义依据与项目选定的画法应分别保留。

一条语义关系可以有几种候选画法，一种视觉关系也可以服务于不同诗句。绘图程序从已定义的方式中选择和组合，不执行 LLM 临时生成的绘图代码。

## 3. 候选视觉关系表

下表的名称与方向作为本版讨论约定。代码标识只用于后续设计讨论，**尚不是当前 API 协议允许返回的新枚举**。本表列候选能力，不要求第一版一次实现全部类型。

“主体”表示这一视觉关系的主要参与者，不一律等于施加作用的人；具体方向以每一行的定义为准。参与者可以是一个形态或明确的一组形态。

| 名称／讨论标识 | 主体 → 对象或参照 | 候选表现 | 必须保留的区别 |
| --- | --- | --- | --- |
| 连接 `connect` | 两端或多个待连接形态 | 线、桥、连续边界、接触点 | 连接不必融合成同一主体 |
| 靠近 `approach` | 移动者 → 接近的参照 | 缩小距离，路径向对方延伸 | 不保证最终接触或完成 |
| 远离 `separate` | 离开者 → 被远离的参照 | 距离增大，路径分开 | 远离本身不表示厌恶或排斥 |
| 排斥 `repel` | 排斥的一方 → 被影响的一方 | 接近时偏转、绕开、保持间隙 | 包含阻止接近的相互作用，不能由普通远行自动推得 |
| 包围 `surround` | 外围形态或群组 → 中心形态 | 环、弧、外围边界、围绕分布 | 可以是开放或闭合结构；包围的情绪需结合语境 |
| 牵引 `lead` | 带动者 → 跟随或响应者 | 方向、局部形变或运动受另一者影响 | 可只改变旗面的形变，不必让旗整体离开固定位置 |
| 承载 `carry` | 承载体 → 被承载形态 | 整体随载体运动，保留局部变化 | 舟载人：舟 → 人 |
| 依附 `attach` | 依附者 → 支撑或来源 | 保持相对位置，局部生长或摆动 | 方向与承载不同；白发依附远客：白发 → 远客 |
| 阻隔 `block` | 障碍或边界 → 受阻者或路径 | 截住、积聚、停留、绕行 | 阻隔要有依据或明确的艺术选择，不凭空补出实体墙 |
| 穿越 `cross` | 穿越者 → 被穿过的边界或区域 | 穿过缝隙、边界或形态 | 穿越不自动意味着破坏、占领或融合 |
| 汇聚 `converge` | 多个参与形态 → 共同区域或目标 | 路径靠拢、局部聚集 | 汇聚不自动增加参与者数量 |
| 分散 `disperse` | 原有群组 → 可选参照区域 | 向不同方向展开、拉开间距 | 分散不等于消失；主体可继续存在 |
| 交织 `interweave` | 多条路径或形态相互参与 | 穿插、交错、缠绕 | 相交不必建立连接或合并身份 |
| 遮蔽 `occlude` | 遮蔽者 → 被遮蔽者 | 前后层次、覆盖范围或遮罩变化 | 暂时看不见不等于不存在 |
| 显露 `reveal` | 被显露的形态 → 可选遮挡参照 | 遮挡退去，轮廓逐步可见 | 无明确揭示者时不补出施事；不擅自断言形态刚刚诞生 |
| 呼应 `echo` | 相互对应的形态 | 共用轮廓、节奏、重复结构或错相响应 | 不强制画连接线，也不默认二者有因果关系 |
| 对照 `contrast` | 相互比较的形态 | 大小、疏密、方向、形态或节奏差异 | 颜色仍在已选情感方案内组织，不自行替换配色 |

## 4. 不直接当作空间关系的内容

### 比喻

“戈鋋若罗星”先识别兵器为主体、罗星为参照。视觉上可以借用群星的分布特征，也可以试验闪烁节律；闪烁是候选艺术表达，不是原文已经给出的动画指令。

不因出现“若”就连接两组实体，也不自动添加一片真实星空。比喻参照怎样参与绘制，应在视觉选择中明确记录。

### 生长、消散与形变

这些可以是单个意象随时间发生的过程。涉及另一主体时再记录关系，例如“白发从远客生”可组织为依附关系，加上局部生长过程。不要为了填关系表而虚构另一个参与者。

### 否定、可能和假设

它们属于逻辑指标，负责关系是否成立及其适用条件。“不连接”不能直接改写为“排斥”，“可能靠近”也不能直接当成已经靠近。详见 [逻辑指标规范](逻辑指标规范-v1.md)。

## 5. 每项视觉选择需要记录什么

本节是设计记录要求，不是对现有 JSON Schema 的修改。

| 记录项 | 要求 |
| --- | --- |
| 关系名称 | 从候选类型中选择；尚不支持时保留待确认，不临时造同义类型 |
| 参与主体与对象 | 指向已经识别的意象；多人、多物需说明是一个群组还是不同主体 |
| 方向 | 按关系定义写清，尤其承载、依附、遮蔽、牵引 |
| 文字依据 | 保留连续原文片段；不存在直接依据时明确是推断或艺术选择 |
| 选择依据 | 区分文字直接支持、语境推断、用户指定的表达 |
| 逻辑适用范围 | 说明哪条联系成立、被否定或受条件限制 |
| 时间接口 | 说明展开方式由哪些文字提示支持，哪些只是候选播放方案 |
| 强度接口 | 在不反转关系含义的前提下，调整紧密度与空间利用 |
| 待确认内容 | 记录歧义、冲突、缺失的对象或尚未决定的画法 |

同一实体的复指应合并，例如“归舟”和后句的“舟”可以是同一条船；重复提及不能自动创建新主体。没有明说的观看者可以保留未知，不以身体姿态补全场景。

## 6. 与其他指标共同工作

- 情感提供颜色方案，关系不另选一套颜色。
- 强度改变空间组织，但不能把排斥改成吸引，把分散改成汇聚。高强度的排斥可以表现为各形态内部笔触更密、整体向外撑开，不必全部挤在中心。
- 逻辑限制具体关系的成立和完成。被否定的靠近可以表现为无法接近，但要避免由此擅自推断仇恨。
- 时间决定变化过程。靠近可以一次发生、持续展开或保持趋近；反复与循环需要文字依据或明确的艺术选择。

当前语义协议 3.0 负责保存语义数据；本表的视觉关系属于后续绘图层。二者不能仅按相似名称机械替换。

## 7. 用户样本的候选映射

以下均为设计例，不是已经实现的画面，也不是重新调用模型的结果。

| 诗句 | 可保留的语义 | 候选视觉组织 |
| --- | --- | --- |
| 西风酒旗市，细雨菊花天 | 风与旗面的联系，雨、花、市井的并置 | 风牵引旗面局部形变；旗保留依附点。具体雨花响应可另行试验 |
| 十月到幽州，戈鋋若罗星 | 兵器为主体，群星为比喻参照 | 借用群星分布组织兵器形态，不自动创建真实星空 |
| 长风万里送秋雁，对此可以酣高楼 | 风吹送雁群，空间辽阔 | 牵引与穿越；是否远离观看位置属于构图选择 |
| 坐见幽州骑，长驱河洛昏 | 目睹、推进、河洛昏暗 | 穿越与遮蔽可以试验；不据此认定扬尘是唯一成因，也不确定观看者坐姿 |
| 黄华自与西风约，白发先从远客生 | 花与风相应，白发长出，花期与人衰对照 | 呼应、依附、对照；生长过程交给时间指标，先的参照仍待解释 |

## 8. 验收与后续

后续预览至少要让人分清：靠近与连接、远离与排斥、承载与依附、遮蔽与消失、呼应与因果。关系不明确时保留原文与待确认项，不静默替换成随机运动。

可先使用同一组形态、同一配色和同一强度，对照候选关系；再比较不同强度下关系含义是否保持。本文尚未完成这些视觉测试，也未规定具体距离、速度、力、密度或面积数值。

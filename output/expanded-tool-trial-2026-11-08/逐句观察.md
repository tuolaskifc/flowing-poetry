# 扩大模型选笔试验

十组有出处的原句见 cases.json，其中 e03 在既有运行记录中出现过两次，其余九组在项目 runs/result.json 中未找到相同短句，不代表没在其他资料中出现。每句先请求诗句解读，再请求阅读工具目录的选笔建议；20 次请求的返回用量合计 102,447 token。e02 的选笔回复不符合结构要求，未自动重试；其余九组绘制对照，浏览器绘制没有模型请求。

两侧使用同一份语义、种子和固定交融模式；左侧现行工具映射，右侧允许采用模型建议的不同已有工具。局部源词安全规则、原文在场状态与工具限制仍生效。模型建议不总能执行：landscape 有多种形态时仍需本地既有映射确定具体形态；风等参数保留原规则。模型自由文字构图没有被程序执行。对照中细小的动画帧或笔触差异不直接归因于模型选笔。

| 诗句 | 观察 |
| --- | --- |
| e01 一道残阳铺水中 | 左右都以水和交融线场表达；模型建议山水光影但没有可执行的具体形态，残阳仍是缺口；半江两色未得到可靠表达。 |
| e02 行到水穷处 | 解读返回，但选笔建议顶层字段不符，未生成选笔对照；不计为选笔成功。 |
| e03 荷风送香气 | 模型建议荷风不画实物，但本地风参数相关路径仍保留荷叶；竹露借竹形，声音和气味未被直接表达。左右差异不明显，也不是模型建议完整执行。 |
| e04 落霞与孤鹜齐飞 | 两侧均有一只飞鸟、水及天空色层；天水同色与霞鸟关系仍需审美和原文复核。 |
| e05 人闲桂花落 | 模型选择落花笔触，替换原先直立花形；春山借山形补进。是否保留人影需考虑“人闲”的解释和画面效果。 |
| e06 明月别枝惊鹊 | 两侧月、枝、鸟相近；鸟惊飞的过程未可靠表现，蝉列为缺画法。 |
| e07 月黑雁飞高 | 模型选择人物表现单于，右图出现人影；两侧仍画明亮弯月，与“月黑”有明显张力，不能以出图算成功。 |
| e08 潮平两岸阔 | 模型选岸形，右图加岸；舟身借形一帆，但缺帆，开阔与风的效果待审。 |
| e09 大漠沙如雪 | 模型选山形，右图显示燕山；大漠沙无可靠画法，不能把雪或钩的比喻参照补成真实主体。 |
| e10 独坐幽篁里 | 模型为“幽篁”选竹，使右图由通用树改成竹；琴出现，但独坐、弹琴的人物未被这次解读可靠表现。 |

这些是单帧检查，不代表动态与用户审美验收；模型选择的能力边界和本地实际工具也可能不一致。审计文件 render-audit.json 列出模型建议、原本画笔、实际画笔及缺口。自动结构通过不等于忠实诗义。实验没有接入正式 API 请求路径，正式入口仅调整了自动表达的交融推荐条件。
